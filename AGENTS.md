# Read the brief before starting work

`docs/master-brief.md` is the live progress ledger for this project: every
requirement Damien has asked for, with its current status. Read it first, work
from it, and **tick items off in the same commit as the work**. It exists because
this project is larger than one context window and nothing is allowed to be
missed.

`docs/briefs/` holds the source prompts verbatim. The ledger is the checkable
version; the briefs are the authority on what was actually asked for.

The "Standing constraints" and "Blocked on you" sections at the top of the ledger
override any plan you would otherwise make.
